## Technology decisions (summary — rationale in `16_decisions.md`)

| Concern | Choice |
|---|---|
| API runtime | Python 3.12, FastAPI, Uvicorn |
| Persistence | PostgreSQL 16, SQLAlchemy 2.0 (async), Alembic migrations |
| Validation / schema | Pydantic v2; OpenAPI 3.1 generated by FastAPI at `/api/v1/openapi.json` |
| Background jobs | Redis 7 as broker/transport; **job state of record lives in PostgreSQL**; RQ worker process with DB-backed leases + idempotency + item mutation keys |
| Sessions | Server-side sessions in PostgreSQL; opaque HttpOnly `Secure` `SameSite=Lax` cookie |
| Password hashing | Argon2id (`argon2-cffi`) |
| Web UI | React 18 + TypeScript + Vite; React Router; TanStack Query for server-state; Radix primitives for accessible dialogs/menus; hand-rolled design system (PRS §14) |
| Reverse proxy / static | Caddy (TLS-ready, serves built SPA, proxies `/api`) |
| Attachments | Local persistent Docker volume (PRS §12); storage behind a `BlobStore` interface |

## Cross-cutting rules enforced in the domain layer (PRS §21)

1. Every write path — GUI, REST, CSV import, bulk job, future automation — calls the
   same **domain service** functions. Controllers/handlers do transport only.
2. Authorization is evaluated inside the domain service for **every** operation
   against concrete conditions (actor is member, actor owns/assigned), not role names.
3. Immutable records: `test_case_version` content, cycle-test step snapshot,
   completed `execution_attempt`, `trace_link` origin, `audit_event`. Corrections are
   new append-only `execution_correction` rows.
4. Optimistic concurrency: every mutable aggregate root carries an integer `version`;
   critical mutations require `If-Match`/`expected_version` → `409 VERSION_CONFLICT`.
5. Every project-owned FK is validated to share `project_id`. Cross-project links →
   `422 VALIDATION_ERROR`. (PRS §5)
6. All metrics resolve through one `reporting` service returning
   `{scope, filters, data_as_of, numerator, denominator, formula_version, refreshed_at}`.
7. Audit event written in the same transaction as the mutation it records.
8. Phase 2/3/4 concerns are represented only as interfaces (`ExternalSyncPort`,
   `AutomationIngestPort`, `AiGenerationPort`) with no Phase 1 implementation.
